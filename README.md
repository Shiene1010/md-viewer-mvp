# MD 뷰어 최소버전

인간과 에이전트의 공통 작업물로서 MD를 주고받는 최소 뷰어.
사람은 렌더만 보고, 원문·검수는 에이전트가 맡는다.

## 실행

```sh
python3 server.py
# http://127.0.0.1:8123
```

## 기능

- 좌 사이드바 파일 탐색, 렌더창 [벽|문서] (벽형/대시보드/조약돌 카드)
- 벽 카드 드래그 정렬, 버전 스냅샷(v1~v6), 검색·목차·다크·단축키
- 하단 채팅: 로컬 OpenCode 프록시(`/oc`)로 선택 모델이 MD를 읽고 개선, 반영 시 버전+1
- PWA, 오프라인 벤더(`vendor/`)

## 하단 채팅 전제

OpenCode 서비스가 같은 머신에서 실행 중일 것 (`~/.config/opencode/service.json`).
비밀번호는 브라우저에 노출되지 않고 `server.py`에만 머문다.
